# NovelAI 功能核对 · 2026-10-09

NAI 生图台 0.2.12 跟进当前文生图流程相关功能。功能说明来自官方公告和当日公开生产界面；这份核对不代表所有 NovelAI 工具均已移植。

| 官方更新 | 本软件处理 |
| --- | --- |
| 2026-10-08：V5 Full Medium / High | 已接入 `nai-diffusion-5-full-medium` 专门模型。Medium 固定 14 步、Euler Ancestral、Heavy 负面预设；不发送自定义主/角色负面词或 CFG Rescale。编辑器保留原值供 High 使用，历史记录本次有效设置。 |
| V5 角色定位与更多角色 | 角色上限按当前官方界面设为 32 个输入栏；V4 系 6 个。保留模型切换时的草稿，超过同时使用上限时阻止生成并提示停用。支持自由坐标、拖动和键盘微调。公告中展示的 22 个可区分角色是生成示例，与当前输入栏上限不同。 |
| V5 透明背景 | 请求中追加透明背景标签并使用 PNG / straight alpha；是否生成理想透明效果仍取决于模型结果。关闭背景选项不删除用户手写的透明标签。 |
| V5 Standard / Light 质量标签 | 在请求副本中追加对应官方质量词和参数提示；关闭质量标签后不追加。旧收藏和名称标签文本不被覆盖。 |
| V5 引号画面文字 | 可将主提示词和启用角色里的成对引号内容按编辑顺序追加为 `teXt:` 区块；支持英文引号、弯引号和日文括号。已有 `Text:` 时沿用手写内容。复杂漫画的阅读顺序可关闭自动转换并手写区块。 |
| V5 Opus 使用上限 | 界面与额度不足提示已说明。Medium 默认设置下官方给出的用量约少 42%，软件不把这个比例当作账户费用估算。 |
| 2026-09-07：Pixel Snap | 官方的本地像素画整理工具，当前未移植。 |
| V5 Max Enhance、放大、局部重绘；Canvas 与 3D | 当前软件仍专注单张文生图，这些工具未实现。 |
| V5 Precise Reference / Vibe Transfer | 当日官方生产界面的 V5 能力标记仍为关闭；不显示无法使用的入口。V4.5 的参考工具也未移植。 |
| 文本生成模型与退役公告 | 不属于本软件的图片生成流程。 |

V5 的噪声表按官方请求固定为 Karras。旧模型保留此前的请求结构。High 与 Medium 不保证相同 Seed 下画出相同内容，也不保证所有角色、文字或透明效果均准确。

软件更新增加了固定 GitHub 仓库的正式版本查询，显示版本和更新说明，并打开公开下载页。公开接口限流时，从 GitHub 的最新正式发布页读取版本；这种情况下，更新内容和安装包需到下载页查看。没有自动修改模型列表或下载执行远端代码；后续 NovelAI 接口变化仍需核对、适配、验证并发布新版本。

发布前使用合成数据和模拟服务检查参数、模式切换、历史、定位、更新失败重试与安装包校验；真实付费生成和真人验收单独记录，不由离线测试替代。
