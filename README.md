# NAI 生图台

一个用 React、TypeScript 和 Electron 编写的 NovelAI 图像生成工作台。当前源码版本为 **0.2.11**，主要支持 Windows 桌面端，也可在浏览器中开发和预览。

## 功能

- 编辑主提示词、负面提示词和角色提示词，调整模型、尺寸、步数、采样器及 Seed（随机种子）。
- Seed 留空时，每次生成重新抽取；填写固定值或载入历史参数时可重复使用。
- “我的提示词”保存常用内容，插入后显示名称小框，支持查看全文、单独移除、撤销及展开编辑；生成仍使用完整文本。
- 按语法为提示词着色，支持角色名称、启用开关与位置设置。
- 预览、缩放、下载和复制生成图片，保存本机历史并载入历史参数。
- 连接自己维护的本地提示词库，搜索词条和配方并插入编辑框。
- 配置兼容的识图接口，从图片提取提示词。
- 演示模式使用本地占位图，可在没有 Token 的情况下体验编辑和历史流程。
- Windows 安装器支持本地覆盖更新及配套 SHA-256 文件校验。

## 从源码运行

准备 **Node.js 24 或更高版本**和 Git，然后执行：

```bash
git clone https://github.com/gothamkismet-cyber/nai-image-studio.git
cd nai-image-studio
npm ci
npm run desktop
```

`npm ci` 按 `package-lock.json` 安装依赖；首次安装需要联网下载依赖及 Electron。`npm run desktop` 先构建再打开桌面窗口。

开发界面时，在两个终端分别运行：

```bash
npm run dev
```

```bash
npm run desktop:dev
```

也可直接在浏览器打开 `http://localhost:5173`。运行 `npm run build` 后，可用 `npm run preview` 预览构建结果。

## 首次使用

1. 启动后可先开启“演示模式”，体验操作流程。
2. 真实生图需要自己的 NovelAI 账号、可用的 API Token，以及能够访问 NovelAI 服务的网络。
3. 在“API 配置”里填写 Token，按需测试连接并保存，再填写提示词和参数，手动点击生成。
4. 识图功能使用单独的服务地址、API Key 和模型配置；图片会发送到你选择的服务。

真实生成和识图可能消耗所用服务的额度，具体以服务商规则为准。

## 接入提示词库

本仓库包含词库读取代码，**不附带作者的本地词库、社区配方数据或用户收藏**。没有词库也可手动编辑提示词，使用“我的提示词”和演示模式。

在桌面端的“本地词库”中选择自己的目录；程序也保留对 `D:\nai提示词` 的默认探测。目录中的 `data*.js` 应提供 `window.NAI_DATA`，可选的 `index.html` 用于指定数据脚本加载顺序。浏览器端需要支持目录选择的浏览器并在本地开发地址或 HTTPS 页面上授权读取。

词库读取不会修改原文件；脚本在独立、禁止联网的环境中解析。仍应使用自己维护、信任的词库，并分别核对所用数据的授权。

## 构建 Windows 安装包

```bash
npm run dist
```

安装器、便携版及安装器的 `.exe.sha256` 校验文件输出到项目内的 `release/`。仓库不保存这些生成文件。

建议将项目放在不含中文的目录中构建安装包；打包工具曾在中文路径下出现解压或重命名失败。也可单独指定输出位置：

```bash
npm run dist -- --config.directories.output=C:/nai-release
```

项目未配置代码签名。哈希文件用于核对文件完整性，不证明发布者身份。本地更新流程不会自动联网下载安装包。

## 检查

```bash
npm test
```

该命令先完成 TypeScript 检查与 Vite 构建，再运行三组独立 Electron 检查：提示词名称标签、随机种子和个人提示词。检查使用临时用户目录、合成内容及模拟响应，阻断外部网络请求，不调用付费生成接口；报告保存在命令输出的系统临时目录。

`scripts/` 中还保留了其他专项检查。其中部分依赖作者的本地词库、旧版本源码备份或安装包，不在默认 `npm test` 范围内。自动检查不等同于真实服务端生成验证。

## 数据与隐私

Token、识图配置、编辑参数和个人提示词保存于本机 `localStorage`，生成历史保存于 `IndexedDB`；桌面端另在用户数据目录的 `config.json` 中记录词库路径。**这些凭据不是加密保存的**，请保护自己的电脑及应用数据目录，不要把用户资料、导出配置或带凭据的日志提交到仓库。

NovelAI 请求直连代码中配置的官方接口；识图请求发送到用户指定的服务。桌面端与普通浏览器使用各自的存储，默认不会同步收藏、凭据或历史。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `src/` | React 界面、参数、请求、历史与提示词逻辑 |
| `electron/` | 桌面主进程、窗口桥接、词库隔离读取和本地更新 |
| `scripts/` | 开发启动、图标生成及功能检查 |
| `build/` | 应用图标、安装器许可和校验文件生成钩子 |
| `package-lock.json` | 固定依赖安装结果 |

目前没有图生图、局部重绘或批量生成功能；其他操作系统的安装包未验证。服务端接口可能变化，遇到问题可在 [Issues](https://github.com/gothamkismet-cyber/nai-image-studio/issues) 中提供复现步骤，先移除 Token、API Key 和私人内容。
